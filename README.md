This repository goes hand-in-hand with the manuscript "Persistence of n-Species Lotka–Volterra Models with Periodic Pulses".

The file is a MATLAB script that can be run directly on MATLAB. It will produce the figures displayed in Figure 2 and 3. It thus also demonstrates how the other figures can be created with some minor modifications.

# References:
Courcelle, E., MacDonald, J. S., & Patel, S. (2026). Persistence of n-Species Lotka-Volterra Models with Periodic Pulses. arXiv preprint arXiv:2609.09343.
